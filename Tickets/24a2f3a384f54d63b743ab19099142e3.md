# Remove Nerdbank.GitVersioning; versions come from the publisher

Upstream microsoft/MSBuildCache is dead; this fork owns its versions. Remove the Nerdbank.GitVersioning GlobalPackageReference and version.json. NBGV was the only version source (no Version/VersionPrefix anywhere; nothing reads ThisAssembly or git version properties; no CI uses nbgv). Publication through publish_localnuget without packageVersion now selects the next patch above project versions (SDK default 1.0.0) and the feed (highest 0.2.6-preview-g42c947acbc), so the first release will be 1.0.1. Motivation: height-based versions regressed after reconciliation (ticket 913973b7: 0.1.344 below deployed 0.1.356), detached publication checkouts always produced -g<sha> suffixes, and NBGV needed special handling in NuGetManager.Publishing. MicroBuild.Core is intentionally out of scope.
