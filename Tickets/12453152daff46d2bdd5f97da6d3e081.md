# Expose the existing MSBuildCache engine for in-process project target reuse

Refactor shared initialization so library callers and the MSBuild plugin reuse the same project parser, source hashing, dependency fingerprints and local CAS cache. Expose open/query/publish on the existing Local plugin, supporting caller-supplied in-process source hashes without launching an MSBuildCache or git helper process. Preserve plugin behavior and observed-output semantics. Integrate with CSharpMpc project-level test caching; validate, publish the package, and commit completed work.

## Summary

Expose in-process project-target reuse through the existing MSBuildCache engine, with short cache ownership and successful-result publication.
Consumer impact: behavior - library callers can reuse target results without starting a cache helper process; ordinary plugin behavior is preserved.
