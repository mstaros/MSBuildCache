# WarningPolicyTests use an SDK-bearing dotnet; msalruntime ticket correction

The four WarningPolicyTests start `DOTNET_HOST_PATH` or bare `dotnet` to run `dotnet msbuild`. Under CSharpMpc the test host is the patched runtime, which has no SDKs, so all four fail with "No .NET SDKs were found".

- Use the SDK host CSharpMpc names (CSHARPMPC_SDK_DOTNET), then DOTNET_HOST_PATH, accepting each only when its installation has an `sdk` folder; otherwise keep the current `dotnet` fallback.
- Ticket a6c8b33d (8a058dd) says the package stopped packing msalruntime.dll; the package never contained it, so remove those claims.

## Summary

WarningPolicyTests run MSBuild with an SDK-bearing dotnet (CSharpMpc's configured SDK first), so they pass when the test host is CSharpMpc's patched runtime. Ticket a6c8b33d no longer claims msalruntime.dll stopped shipping.
Consumer impact: none
